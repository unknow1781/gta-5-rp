Privacy Policy

1. Information Collection

1.1. Legacy RolePlay may collect basic user information including Discord username, IP address and gameplay activity for security and moderation purposes.

1.2. Information is collected only to improve server quality, maintain safety and provide better services.

1.3. Legacy RP does not collect sensitive personal information such as passwords or payment credentials.

2. Use of Information

2.1. Collected information may be used for administration, support, anti-cheat systems and community moderation.

2.2. Legacy RP may use gameplay statistics and activity logs to improve server performance and player experience.

2.3. User information will never be sold or shared with third parties without valid legal reasons.

3. Security

3.1. Legacy RolePlay uses reasonable security systems to protect user information from unauthorized access.

3.2. While we aim to keep all data secure, users are responsible for protecting their own accounts and devices.

3.3. Any suspicious activity or security issue should be reported to server staff immediately.

4. Final Terms

4.1. By using Legacy RP services, the user agrees to this Privacy Policy.

4.2. Legacy RP reserves the right to update this policy at any time without prior notice.

4.3. Continued use of the platform after updates means acceptance of the revised policy.
